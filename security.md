# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the affected repository, go to the **Security** tab, and choose **Report a vulnerability**. That sends the report only to the maintainer.

Include:

- the repository and the commit or release you tested
- what you did, what happened, and what you expected
- the device, OS, or account type involved, if it matters

## What to expect

These are hobby projects maintained by one person. You should get an acknowledgement within 7 days. Fixes are prioritized by how much damage the problem could cause to someone running the tool.

## Scope

Only the code in AI-Gizmos repositories is in scope. Problems in third-party apps, devices, or AI services that a gizmo talks to should go to that vendor.
